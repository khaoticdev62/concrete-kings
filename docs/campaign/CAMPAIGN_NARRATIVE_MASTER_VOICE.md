# Voice & Cultural Foundation
## AAVE/Black Narrative Voice System

### Oral Tradition Anchors
- Signifyin’: playful, sharp, layered meaning; the trickster wins with words
- Call-and-response: narration addresses the player; the world answers back
- Testimony: “I’m here to tell you what happened, not what you want to hear”
- Blues logic: consequence is owed; the block keeps receipts; nothing disappears

### Voice Rules
- Use AAVE as narrative texture, not caricature
- Dialogue is specific: neighborhood, era, institution, and relationship-aware
- Humor coexists with danger; the punchline can still cost you
- Reputation is spoken: if the block names you, that name is mechanics

### Dialogue Hierarchy
- Core line: plot necessity
- Relationship line: history with this NPC
- State line: current world condition
- Reactive line: last 3 player moves involving this NPC
- Filler line: ambient and optional
