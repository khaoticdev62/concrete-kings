PART 2 — ELITE MINI GAME MECHANICS (FULL DETAIL)
================================================

CORE LOOP:
  EXPLORE -> INTERACT -> PLAY MINI GAME -> RESOLVE -> REPEAT

STATE MACHINE:
  IDLE -> LOBBY -> PLAY -> RESOLVE -> REWARD -> EXIT -> IDLE

GLOBAL RESULT PAYLOAD:
  success: boolean
  tier: critical | success | partial | failure
  trustDelta: number
  heatDelta: number
  cashDelta: number
  reputationDelta: string
  secretsUnlocked: string[]
  flagsSet: string[]
  items: { add: [], remove: [] }
  questUpdates: { id, stage, newFlags[] }

DIFFICULTY:
  Easy:     DC  8-10
  Medium:   DC 11-13
  Hard:     DC 14-16
  Extreme:  DC 17-18

ATTRIBUTES:
  STR  -> physical, stealth, climb, force
  WIT  -> puzzles, negotiation, hacking, locks
  SOUL -> social, leadership, empathy, intimidation
  CASH -> purchases, bribes, gear, entry

SUCCESS TIERS:
  Critical: >= DC + 6
  Success:  >= DC
  Partial:   >= DC - 5
  Failure:   < DC - 5

FAILURE RULES:
- Failure applies heatDelta +2 minimum
- Partial applies heatDelta +1 and cashDelta penalty possible
- Critical may unlock secret or remove heat

MINI GAME CATALOG
1. Haircut Challenge
   Type: timing window
   Trigger: Ray / shop hours
   Mechanics: hit 8 timing windows with fade-in/out markers; straight razor bonus removes 1 miss
   Rewards: cash, rep + neat, trust
   Failure: cut too short -> cash penalty, rep - messy

2. Street Dice
   Type: roll + modifier
   Trigger: hustler NPC, alley
   Mechanics: 2d6 + WIT modifier vs DC; hidden opponent roll
   Rewards: cash pot, trust
   Failure: lose ante, heat +1

3. Lockpicking
   Type: timing + skill
   Trigger: door, safe, locker
   Mechanics: 6 tumbler windows; each success advances pin; 3 pins needed
   Rewards: access, secret chance, trust
   Failure: alarm trigger, heat +2

4. Alley Chase
   Type: grid movement/stealth
   Trigger: ambush, escape
   Mechanics: tile grid, Marquez AI with 2-tile lookahead; hide in shadow = pause timer
   Rewards: safety, secret, trust
   Failure: caught -> cash loss, heat +3, item loss

5. Negotiation
   Type: social check
   Trigger: vendor, bodega, debt
   Mechanics: 4-round bid/ask with WIT/SOUL bonuses; hidden NPC floor/ceiling
   Rewards: lower price, info, trust
   Failure: pay full price or leave

6. Barber Challenge
   Type: rhythm/timing sequence
   Trigger: barbershop contest
   Mechanics: repeat 8-beat pattern with increasing speed; perfect/miss/great window
   Rewards: cash pot, rep, secret
   Failure: no prize, heat +1

7. Burner Phone Hack
   Type: puzzle input
   Trigger: tech NPC, safe house
   Mechanics: 4-digit code with 2 clues; 3 attempts; each wrong attempt increases police proximity
   Rewards: secret, cash, trust
   Failure: phone bricked, heat +2

8. Gossip Network
   Type: knowledge puzzle
   Trigger: bar, bodega
   Mechanics: connect 5 nodes in correct order using overheard clues; 1 wrong node allowed
   Rewards: secret, quest flag, rep
   Failure: misinformation, heat +1

9. Crafting
   Type: resource selection
   Trigger: safe house, workshop
   Mechanics: choose 3 ingredients from 6; recipe requires exact combo or 4-of-5 substitute
   Rewards: item, cash, trust
   Failure: wasted materials, heat +0

10. King of the Block
    Type: social vote
    Trigger: block event
    Mechanics: 3-round voting; each round you campaign using 1 attribute spend; majority wins
    Rewards: rep, district control flag, cash
    Failure: lose influence, heat +1

INPUT ABSTRACT MAP:
  confirm, cancel, up, down, left, right, action1, action2, pause

Implementation requirements:
- requestAnimationFrame loop with delta-time
- Input state stored each frame; resolved inside update()
- 4-frame animation budget for all motion/animation
- 1280x720 native overlay canvas; scaled to display
- Controller + mobile + keyboard-only completion path
- Exactly one completion event per mini game

Event rules:
- On resolve, set miniGameResult object and freeze input
- Do not mutate world state until RESOLVE state
- Reward/penalty application happens in REWARD state only

CHARACTER PROMPT RULES:
- Start every character prompt with identity line
- Add one signature prop in every variant
- Lock seed per character ID; reuse seed for all variants
- Generate portrait at 2x, then downscale to 64x64 or 128x128

CARD ART RULES
Black cards:
- Allegorical scene or object, not a specific face
- Readable at thumbnail size
- Aspect 2:3
- Two max focal elements
- Background simplified to silhouette

White cards:
- Bust portrait, identity-locked character or archetype
- Thumbnail-readable face
- Rim light required
- Background dark/none

CINEMATIC / CUTSCENE RULES
- Aspect 16:9
- Noir composition: foreground silhouette, midground action, background light source
- Rim light on hero; antagonist stays in shadow until reveal
- Color grade: desaturated shadows, warm highlights, grain
- 4-frame animation budget for camera moves or environmental motion

CONSISTENCY RULES:
- Lock seed per character ID
- Same prompt structure for variants; only change action, view, atmosphere
- Generate at 2x target resolution, then nearest-neighbor downscale
- Manual cleanup: remove anti-aliasing, enforce hard edges, quantize to locked palette
- If two assets must match, generate both in one batch with same seed and style stack

PIPELINE WORKFLOW:
  1. Write DNA-locked prompt
  2. Generate at 2x target resolution
  3. Downscale with nearest-neighbor
  4. Remove gradients that break cel shading
  5. Quantize palette to allowed colors
  6. Test at play resolution; if unreadable, simplify silhouette

QUALITY CONTROL:
  [ ] Silhouette reads before detail
  [ ] Palette locked to approved colors
  [ ] No blur, no anti-aliasing
  [ ] Character DNA preserved across variants
  [ ] Card art readable at 128x192 px
  [ ] Cinematic readable at 320x180 internal
  [ ] Transparent backgrounds where required
  [ ] Seed recorded in asset manifest

FAILURE MODES & FIXES:
  Too much detail:     Add simple shapes, readable at small size
  Wrong palette:       Append locked palette hex values
  Blurry edges:        Add clean edges, flat cel shading, no anti-aliasing
  Photorealistic:      Add pixel art, 16-bit style, game sprite
  Inconsistent style:  Lock seed, reuse exact style stack
  Busy composition:    Add single focal object, shallow depth
  Wrong era:           Add present day, modern urban America, 2020s
  Too dark:            Add visible subjects, readable at play size
