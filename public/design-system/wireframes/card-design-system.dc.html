The Block Chronicles — Card Design System

Griot Modernism: traditional Black visual culture meets premium digital craft. Warm, dimensional, ceremonial — barbershop gold, cookout orange, block-party energy. Never sterile, never flat.

08 · Layout & Access

Responsive + Accessibility Notes

Screen structure
  • Max width 1100px desktop, fluid mobile
  • Panels: rgba(0,0,0,.35), 1px white/8% border, 14px radius
  • Hand grid: minmax(170px,1fr) desktop, minmax(140px,1fr) mobile, 10px gap; horizontal scroll under 360px
  • Status messages: #fff3e0 bg, 2px orange border, Jakarta 600 14px
Accessibility (mandatory)
  • Cards: role=button, tabindex=0, full-text aria-label
  • Keyboard: Tab + Enter/Space select, Escape deselect
  • 3px orange focus outline on everything interactive
  • aria-live regions for round + status announcements
  • prefers-reduced-motion swaps springs for fades
  • Contrast ≥ 4.5:1 everywhere
Print production
  • Cards never break across pages (break-inside: avoid)
  • print-color-adjust: exact preserves gradients + gold
  • Animation controls hidden in print
  • Cream page background replaces the dark desk
Status message pattern — "Marcus is the Griot this round. Everybody else, play your card."
