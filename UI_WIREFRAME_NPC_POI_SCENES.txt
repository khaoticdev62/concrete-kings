NPC STATE RULES
- Friendly: green indicator, full interaction set
- Neutral: amber indicator, limited trade/talk only
- Hostile: red indicator, confrontation or leave only
- Scared: gray indicator, minimal dialogue, flee option
- Busy: blue indicator, wait or interrupt with risk

DIALOGUE RULES
- Choices tagged with trust+/-, heat+/-, secret trigger, item requirement
- If requirement missing: choice grayed, tooltip shows requirement
- Leave option always present unless quest-required scene

INTERACTION TYPES
- Talk: advances dialogue beat
- Quest: shows available quest stages
- Trade: opens item/cash exchange
- Mini Game: launches skill challenge
- Leave: exits scene with no penalty unless hostile
