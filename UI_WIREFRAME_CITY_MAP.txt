MAP LEGEND
  @  = player
  R/J/M/K = NPCs
  * = active quest
  ? = hidden quest
  ! = urgent quest
  # = fog / unexplored
  B = barbershop
  D = bodega
  A = alley
  H = safe house
  P = park

TILE RULES
- Grid aligned to 32x32 pixel units
- Fog hides unexplored tiles and hidden quest tiles
- Fast travel unlocks only after visited tile is cleared of active heat
- NPC blink red if hostile, green if friendly

CONTROLS
- D-pad / arrows: move cursor
- Confirm: select tile / travel
- Cancel: back to game
- Zoom in/out: increases tile detail level
