GAME BOARD / MAIN GAMEPLAY
- Default state: top HUD, center story panel, lower state + action bar
- Card selected: card zooms, options highlight, hint text appears
- Judging: timer panel + voting panel + result preview
- Resolution: narrative text + stat delta panel
- Ending: full-screen story beat, final stats, restart/new game
- Narrative beat mode: story text lives in #narrativeTextBox inside the stage panel, with choices and stat readouts

TRANSITION RULES
- Judging must resolve within 12 seconds or auto-randomize
- Resolution panel stays for 5 seconds or until confirm
- Ending screen requires confirm to proceed
- Narrative beat opens in the stage panel as the active story view

INTERACTION MAP
- D-pad / click: move focus
- Confirm: select card or option
- Cancel: back to default or close zoom
- Bumpers / shortcuts: quick action bar

PANEL PLACEMENT RULES
- Story panel always fills the central narrative focus
- Narrative text box uses the stage panel when active
- State panel stays left-lower for quick reference
- Card play is always right-lower during play states
- Action bar is always bottom-center in default state
- Judging replaces story panel with timer + voting stack

TEXT LAYOUT RULES
- Max narrative width: 1040 px
- Max choice width: 520 px per choice slot
- HUD font row height: 36 px
- Panel padding: 18 px internal on all sides

STATE TRANSITIONS
- Default -> Card Selected -> Judging -> Resolution -> Default/Ending
- Judgment timeout: 12 seconds then auto-randomize
- Resolution hold: 5 seconds or confirm
- Narrative beat transitions back to default/round flow after choice or resolution
