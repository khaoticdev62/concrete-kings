CHOICE FORMAT RULES
- One action verb + target noun per choice
- Choices tagged with trust+/-, heat+/-, secret trigger, item requirement
- Locked choices show grayed state and tooltip requirement

NARRATIVE TEXT RULES
- Max 110 characters per line
- Beat title left-aligned, uppercase, amber
- Body text left-aligned, white, 1.5 line spacing

UTILITY ACTIONS
- USE ABILITY: opens ability menu if available
- VIEW SECRET: shows current secrets/flags
- OPEN MAP: overlays city map without leaving narrative

DECISION PANEL — LOCKED CHOICE TOOLTIP

- Tooltip appears below choice: requires ITEM_X or SECRET_Y

- Open map -> map overlay -> back returns to narrative
