PANEL PLACEMENT RULES
- Story panel always fills the central narrative focus
- State panel stays left-lower for quick reference
- Card play is always right-lower during play states
- Action bar is always bottom-center in default state
- Judging replaces story panel with timer + voting stack

TEXT LAYOUT RULES
- Max narrative width: 1040 px
- Max choice width: 520 px per choice slot
- HUD font row height: 36 px
- Panel padding: 18 px internal on all sides

STATE TRANSITIONS
- Default -> Card Selected -> Judging -> Resolution -> Default/Ending
- Judgment timeout: 12 seconds then auto-randomize
- Resolution hold: 5 seconds or confirm
