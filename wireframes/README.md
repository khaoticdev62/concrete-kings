# Concrete Kings - Production Wireframes

High-fidelity, production-ready wireframes for the narrative RPG card game interface.

## Screens

1. **Character Creation** (`01-character-creation.html`)
   - Origin story selection with 6 options
   - Hidden stat preview system
   - Hover/selection states with visual feedback

2. **Main Game Screen** (`02-main-game-screen.html`)
   - 3-column layout: Players/Receipts | Play Area | Block Map Mini
   - Black card with Cipher dice indicator
   - Hand grid with selection states
   - Real-time stat tracking

3. **Judge Phase** (`03-judge-phase.html`)
   - O.G. authority banner
   - Submission cards with player attribution
   - O.G. powers panel (veto, receipts, Cookout Summit)
   - Receipt assignment system

4. **Round Result** (`04-round-result.html`)
   - Winner celebration card
   - Stat changes for all players
   - Receipt earned notification with future hook
   - Narrative continuity moment

5. **Block Map** (`05-block-map.html`)
   - Spatial visualization of The Block
   - Location bonuses and player positions
   - Relationship lines (alliances/beef)
   - Interactive location cards

6. **Cookout Alliance** (`06-cookout-alliance.html`)
   - Alliance formation with member selection
   - Hustle-specific bonuses preview
   - Ghosting mechanic with consequences
   - Rule reference box

7. **Game Over** (`07-game-over.html`)
   - Champion celebration with stats
   - Final standings with hustle types
   - Receipt summary (resolved vs active)
   - Share/play again actions

## Design System

- **Colors:** Black (#1a1a1a), Orange (#ff6b35), Cream (#f3e7cf)
- **Typography:** Segoe UI, system font stack
- **Components:** Cards, panels, buttons, badges, stat bars
- **States:** Hover, selected, disabled, active, hostile
- **Breakpoints:** Desktop 3-col → Tablet 2-col → Mobile 1-col

## Usage

Open any HTML file in a browser to view the wireframe. Each file includes:
- Full visual design with annotations
- Interaction states documented in notes
- Mobile responsiveness notes
- Accessibility considerations
