Black Card Design Notes

  • Dark gradient creates visual authority; cream text provides high contrast
  • Dice badge positioned top-right for immediate recognition
  • Prompt uses orange underline for blanks—consistent with brand
  • Receipt variant uses gold border and seal to distinguish from regular scenarios
  • Footer shows round number and active cipher effect for context
  • Mobile: prompt font reduces to 16px, card min-height adjusts

Receipt Card Design Notes

  • Gold/yellow palette distinguishes narrative threads from gameplay cards
  • Slight rotation (-1deg) gives organic, "pinned to board" feel

Cipher Card Design Notes

  • Purple palette differentiates cipher from scenario/response cards
  • Large cultural symbol (🔥 💰 📻 👑 ☮ 🎤) as primary visual anchor
  • Centered layout creates ceremonial feel—cipher is a moment, not just a mechanic

  • Description explains mechanical effect in plain language
  • Symbols chosen from Black cultural lexicon: fire = truth, crown = authority, mic = voice

12 · Card Component Anatomy

Standard Card Structure

🎲
Scenario · Cipher
The prompt text goes here with ____ for blanks
Round X Effect Label

Component Layers

  • Top accent bar: 4px color indicator, 30% opacity
  • Icon: Cultural or contextual emoji, 32-64px depending on card type
  • Type label: Micro text, uppercase, letter-spaced—classifies card category
  • Title/Prompt: Primary text, bold, largest element
  • Body text: Secondary info, regular weight, slightly smaller
  • Footer: Metadata (round, effect, status), smallest text, uppercase
  • Seal/Badge: Absolute positioned status indicator (optional)
